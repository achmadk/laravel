# Design: pos-cart-clear-all

## Backend

### Route

Add to `routes/web.php` inside the existing dashboard transactions group (which already applies `permission:transactions-access` + `active_shift` middleware), **before** any wildcard cart routes:

```php
Route::delete('/transactions/cart', [TransactionController::class, 'clearCart'])->name('transactions.clearCart');
```

Order matters: the literal `/transactions/cart` path must be registered ahead of `/transactions/{cart_id}/destroyCart` so the router does not try to bind `cart` as `{cart_id}`.

### Controller method (TransactionController)

```php
public function clearCart()
{
    Cart::where('cashier_id', auth()->id())
        ->active()
        ->delete();

    return back();
}
```

- Uses the existing `active()` scope on the `Cart` model (same scope the POS `index()` uses to list active items), so held items (those with a `hold_id`) are untouched — matching the user decision.
- Scoped by `cashier_id` so only the current cashier's cart is cleared.
- `return back()` — the page re-reads carts from the DB on the next visit (Inertia refetch), consistent with how the existing `destroyCart`/`updateCart` behave.

## Frontend

### CartPanel (`resources/js/components/pos/CartPanel.tsx`)

- Add optional prop: `onClearAll?: () => void`.
- In the header row (`IconShoppingCart + "Keranjang" + "{n} item" badge`), render a trash-icon button **after the badge**, shown only when `items.length > 0`:

```tsx
{totalItems > 0 && onClearAll && (
  <button
    type="button"
    onClick={onClearAll}
    aria-label="Kosongkan keranjang"
    className="... icon-button styles matching panel (slate colors, ghost hover danger) ..."
  >
    <IconTrash size={18} />
  </button>
)}
```

- Icon-only ghost button, styled with the same plain-slate palette the panel uses (NOT the dashboard token classes — the POS panel uses raw slate).

### `Transactions/Index.tsx`

- Add `isClearOpen` state (boolean, default false).
- Pass `onClearAll={() => setIsClearOpen(true)}` to `<CartPanel>`.
- Add a small confirm `Modal` (pattern from Suppliers/Index.tsx):

```tsx
<Modal isOpen={isClearOpen} onOpenChange={setIsClearOpen}>
  <ModalContent>
    <ModalHeader><ModalTitle>Konfirmasi Hapus</ModalTitle></ModalHeader>
    <ModalBody>
      <p className="text-muted-fg text-sm">Kosongkan semua item di keranjang?</p>
    </ModalBody>
    <ModalFooter>
      <ModalClose>Batal</ModalClose>
      <Button intent="danger" onPress={handleClearAll}>Kosongkan</Button>
    </ModalFooter>
  </ModalContent>
</Modal>
```

- `handleClearAll`: close modal + `router.delete(transactions.clearCart.url(), { preserveScroll: true, preserveState: true })`.

## Types / Wayfinder

- `transactions.clearCart.url()` is generated by Wayfinder from the new named route (regenerate after adding the route).

## Non-goals

- No new DB table/column. Cart rows are deleted (not soft-deleted).
- Held carts (`hold_id` set) are preserved.
